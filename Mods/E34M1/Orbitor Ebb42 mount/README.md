# Modifications – Orbitor Ebb42 Mounts

I modified the **[Ebb42 Mount](https://jon-harper.github.io/E34M1/)** to work with **E34M1 Toolhead** 
These modified parts have not been tested yet. 

**Compatibility Notes:**  
- This modification is only compatible with E34M1 Toolhead.  
- This should work with any part cooling options provided by E34M1 Toolhead

Please ensure your hardware matches these specifications for proper fit and function.

---

## Future Support
Currently testing mounting options to ensure that the ebb42 is secure. I may change mounting or design.
